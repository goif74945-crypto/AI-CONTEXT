## Import policy

Only skill identities and `SKILL.md` registry entries are placed into the category tree. The uploaded archives remain the authoritative source for bundled references, scripts, assets, tests, licenses, and other supporting payloads until those files are copied into the repository verbatim.

This avoids importing unrelated repository tooling such as package managers, CI configuration, and source code from the Skill distribution repositories.
