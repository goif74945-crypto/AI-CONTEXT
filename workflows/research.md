# WORKFLOW — RESEARCH

## Goal
Turn an information need into a source-grounded decision/research artifact.

## Pipeline
`QUESTION → SCOPE → SOURCE PLAN → COLLECT → TRIANGULATE → CONTRADICTIONS → SYNTHESIZE → LIMITATIONS`

## Procedure
1. State the research question and decision it supports.
2. Define scope, freshness window and required source authority.
3. Separate first-party/primary sources from commentary.
4. Collect enough independent evidence to test important claims.
5. Record dates/populations/versions for time-sensitive facts.
6. Build a claim table: claim → source → confidence/evidence → contradiction.
7. Resolve disagreements by source quality and applicability, not majority count.
8. Separate SOURCE FACT / EXTERNAL FACT / INFERENCE / UNKNOWN.
9. Produce conclusions only as strong as the evidence.
10. Persist durable findings if they will affect future work.

## Avoid
- citation laundering;
- using old data as current;
- mixing populations/versions;
- treating search-result snippets as full evidence;
- inventing missing numbers.
