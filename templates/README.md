# AI-CONTEXT Templates

Use these as starting instances of the schemas in `schema/`.

- `task-contract.template.json` — lock objective/scope/authority/preconditions/evidence before mutation.
- `requirement-ledger.template.json` — map requirements to implementation/evidence/status.
- `evidence.template.json` — record exactly what a test/observation proves.
- `execution-record.template.json` — record actions, mutations, verification, blockers and remaining work.
- `decision.template.json` — preserve an explicit decision, rationale, authority and rejected alternatives.

## Rule
Templates are examples, not authority.
Validate real records against the corresponding JSON Schema when possible.
