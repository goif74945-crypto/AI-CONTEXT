## Baseline / reproduction

- Prior local v0.1 tree: 43/43 passing automated tests, deterministic grammar, 12 typed actions, local API, voice/clap UI and ADB adapter.
- Critical functional gaps: blind desktop coordinates, no semantic browser automation, Android limited to 3 actions, no post-action text verification, no app allowlist launcher, no metadata-only trace, stop did not invalidate pending plans, screenshot writes could follow an existing symlink.

## Implemented changes

1. Desktop local OCR target acquisition with confidence threshold and exact normalized Unicode match; reject absent or ambiguous targets without clicking.
2. Desktop `click_text`, `assert_text`, `wait_text`, with bounded timeouts and cancellation.
3. Android ADB swipe, supported system keys, PNG screenshot, UIAutomator hierarchy `tap_text` and `assert_text`. XML parse size limit and entity rejection.
4. Playwright owned Chromium profile with dedicated sync worker thread and semantic DOM open/click/fill/assert/wait/screenshot, never using the operator's personal browser cookies by default.
5. User-owned app alias allowlist executed as argv without shell; no arbitrary unregistered program launch.
6. Optional OCR-to-AI planner context with explicit checkbox consent, sensitive-screen warning and strongly typed output. OCR content remains untrusted data.
7. Metadata-only local append event trail; avoids user command values; audit file mode 0600 where OS supports it.
8. Emergency Stop now invalidates all pending plans and guards concurrent start against a stop-generation change; mid-action cancellation is reported as STOPPED.
9. Desktop/browser screenshot atomic replace and Android screenshot PNG and 16MB validation.
10. Tool contract count increased 12 -> 27; maximum approved steps 12 -> 24; version updated to 0.2.0 and docs updated.
