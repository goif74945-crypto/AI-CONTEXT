# NEXY.AI Task Templates

Reusable task-contract blueprints for common NEXY work.

## Templates
- **FIX_BUG** — Fix a proven defect
- **ADD_API** — Add or modify API route
- **ADD_SYSTEM** — Add NEXY subsystem/system
- **MIGRATION** — Schema/config/state migration
- **SECURITY_FIX** — Repair security defect
- **RELEASE** — Release/deployment readiness
- **AUDIT_SYSTEM** — Audit a NEXY system
- **INGEST_SOURCE** — Ingest large source into AI-CONTEXT

## Rule
Templates are starting contracts, not authorization.
Every run must bind real target, current state, scope, authority and evidence requirements.
