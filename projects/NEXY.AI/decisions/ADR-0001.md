# ADR-0001 — One authoritative output or freeze

**Record type:** SOURCE_DERIVED_ADR  
**Authority:** DOC-B, DOC-C  
**Scope:** CURRENT_REQUIRED

## CONTEXT
NEXY must prevent unresolved internal candidates from surfacing as competing authoritative answers.

## OPTIONS
1. Release multiple candidates and ask user to choose
2. Average candidates
3. Release one verified result or freeze/silence

## DECISION
Release one authoritative final output only after governing verification/release gates; unresolved proof results in freeze/silence.

## WHY
- Preserves one-truth operator model.
- Prevents internal uncertainty from becoming fake authority.
- Aligns UI and release policy with Core/Judge authority.

## CONSEQUENCES
- Internal Top-K may still exist.
- UI must not expose partial candidate as released.
- Release failure is first-class state.

## SUPERSEDES
None explicitly recorded.

## ROLLBACK / CHANGE BOUNDARY
Requires explicit canonical policy change/version; not a local UI change.
