# ADR-0005 — Lo2 may propose evolution but cannot silently rewrite authority

**Record type:** SOURCE_DERIVED_ADR  
**Authority:** Later constitutional law, DOC-C  
**Scope:** CURRENT_REQUIRED

## CONTEXT
Older Lo2 vision described silent intelligence/kernel updates, conflicting with deterministic/versioned governance and current vNEXT exclusion of self-patch.

## OPTIONS
1. Allow silent autonomous mutation
2. Disable learning
3. Allow learning/synthesis but require governed versioned promotion

## DECISION
Lo2 can synthesize/evolve intelligence proposals; authoritative runtime promotion requires explicit version/governance/build/deploy gates.

## WHY
- Prevents hidden drift.
- Preserves provenance and rollback.
- Separates learning from truth authority.

## CONSEQUENCES
- Lo2 learning loop does not equal self-patch permission.
- Promotion needs audit/version evidence.
- Experimental memory remains separate.

## SUPERSEDES
- silent Lo2 self-update as runtime authority

## ROLLBACK / CHANGE BOUNDARY
Would require explicit constitutional/build-spec authorization.
