# ADR-0011 — Current vNEXT excludes future constitutional/game/robotics scope

**Record type:** SOURCE_DERIVED_ADR  
**Authority:** DOC-C  
**Scope:** DOC_C_CURRENT_BUILD

## CONTEXT
The source includes large Sovereign/Game/NCF/Robotics architectures not authorized as current vNEXT obligations.

## OPTIONS
1. Build every source concept now
2. Ignore future architecture entirely
3. Preserve future design context while enforcing explicit current include/exclude scope

## DECISION
Current vNEXT implements DOC-C included systems only; future architectures require explicit spec extension/version/promotion.

## WHY
- Prevents uncontrolled scope explosion.
- Preserves future design without corrupting current build authority.

## CONSEQUENCES
- Ontology may contain future entities with no current code mapping.
- Builders must consult Scope Registry.

## SUPERSEDES
None explicitly recorded.

## ROLLBACK / CHANGE BOUNDARY
Explicit build-spec extension/version change.
