# ADR-0007 — UI reflects truth but does not own truth

**Record type:** SOURCE_DERIVED_ADR  
**Authority:** DOC-B, DOC-C, DOC-D  
**Scope:** CURRENT_REQUIRED

## CONTEXT
Presentation convenience can otherwise mask failure or become an unauthorized mutation path.

## OPTIONS
1. Let UI infer optimistic state
2. Let UI directly mutate authority modules
3. UI renders backend truth and calls authorized boundaries only

## DECISION
UI is a truth surface/control client, not authority; backend authorization and state are canonical.

## WHY
- Prevents fake success.
- Preserves visible != editable != executable.
- Keeps failure/freeze truthful.

## CONSEQUENCES
- No optimistic fake success for blocking actions.
- FREEZE must be visible.
- Backend permission enforcement remains mandatory.

## SUPERSEDES
None explicitly recorded.

## ROLLBACK / CHANGE BOUNDARY
Requires authority-model change, not visual redesign.
