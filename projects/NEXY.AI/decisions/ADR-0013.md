# ADR-0013 — Deprecate the legacy 215-entry NEXY registry

**Record type:** USER_DIRECTIVE + SOURCE_NORMALIZATION_ADR  
**Authority:** explicit current user directive + current normalized source matrix  
**Scope:** NEXY inventory / audit denominator / build-scope enumeration  
**Status:** ACCEPTED

## CONTEXT
AI-CONTEXT contains historical records that treated a 215-entry list as a mandatory or top-level NEXY registry. The current full system/feature build matrix re-normalizes the authoritative NEXY-IGNIS source into 837 source-anchored requirement rows with explicit authority and scope classes.

The 215 list mixes counting units and is not reliable enough to serve as current source truth.

## DECISION
The legacy 215-entry registry is classified:

`DEPRECATED_UNRELIABLE_DO_NOT_USE`

It must not be used for:
- current system counts;
- atomic counts;
- audit/build/completeness denominators;
- current requirement enumeration;
- create/delete decisions.

Historical 215 records are retained only for provenance. They are not deleted because AI-CONTEXT preserves lineage rather than rewriting history.

## CURRENT REPLACEMENT
Use:
- `projects/NEXY.AI/source-normalization/CURRENT-SYSTEM-FEATURE-BUILD-MATRIX.md`
- current normalized matrix: **837 requirement rows**
- source SHA-256: `b35ee1bf8212579251f24914e11aebe103ff697f549f7a5812f07c53361d26b7`
- matrix SHA-256: `7685d962f0f3cd3453faba7853eb571c0e265177f8825d83f4f01a0672657622`

## WHY
- The 215 inventory is historical and not a fresh exhaustive source normalization.
- Its entry granularity is inconsistent.
- It compresses or omits lower-level source requirements and mechanisms.
- The current matrix carries authority, scope and source anchors for each normalized row.

## CONSEQUENCES
- Any prompt, audit, report or memory that says “215 systems” as current truth is stale/unreliable.
- Existing 215-named TASK/CASE/FAILURE/LEDGER records remain historical only.
- The 262-requirement registry remains a prior partial registry, not the exhaustive current denominator.
- The 518-entity ontology remains a typed ontology count, not a system count.
- Future exhaustive source audits must start from the current matrix or a newer explicitly superseding normalization.

## SUPERSEDES
- Any interpretation that the legacy 215-entry registry is a current mandatory denominator.
- Any claim that 215 is a reliable current NEXY system count.

## ROLLBACK / CHANGE BOUNDARY
Only a newer source-normalization artifact with explicit provenance and authority may supersede this decision.
