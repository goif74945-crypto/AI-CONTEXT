# ADR-0004 — Use weighted proof/adversarial survival instead of ordinary voting

**Record type:** SOURCE_DERIVED_ADR  
**Authority:** L600  
**Scope:** CURRENT_ARCHITECTURE

## CONTEXT
Multiple AI models can share correlated errors; vote count is not proof.

## OPTIONS
1. Simple majority vote
2. Trust-score voting only
3. Adversarial attacks + weighted proof + independent verification

## DECISION
Lo3 consensus is proof/adversarial-survival weighted and must not reduce to ordinary majority voting.

## WHY
- Reduces false consensus.
- Rewards proof and independent survival rather than popularity.
- Fits untrusted-worker model.

## CONSEQUENCES
- Context diversity and adversarial engine matter.
- Consensus computation is more expensive.
- Final release still belongs to Judge/Law.

## SUPERSEDES
- ordinary weighted-voting interpretation where conflicting

## ROLLBACK / CHANGE BOUNDARY
Requires explicit Lo3 architecture version change.
