# ADR-0003 — Use bounded truth instead of universal perfect-truth claims

**Record type:** SOURCE_DERIVED_ADR  
**Authority:** L600, Final Architecture  
**Scope:** CURRENT_ARCHITECTURE

## CONTEXT
Older source rhetoric demanded universal 100% truth/zero hallucination, which is not achievable in open-world domains.

## OPTIONS
1. Keep universal perfect truth promise
2. Use confidence only
3. Define truth relative to explicit constraint space and certainty tiers

## DECISION
Adopt bounded truth with T0–T4 certainty semantics and explicit uncertainty.

## WHY
- Avoids pretending unknowns are proven.
- Allows domain-appropriate proof strength.
- Makes freeze/wait behavior principled.

## CONSEQUENCES
- Not every valid output must be T4.
- Uncertainty must propagate.
- Older absolute rhetoric is historical/superseded where it conflicts.

## SUPERSEDES
- universal-perfect-truth rhetoric

## ROLLBACK / CHANGE BOUNDARY
Only by explicit later canonical architecture change.
