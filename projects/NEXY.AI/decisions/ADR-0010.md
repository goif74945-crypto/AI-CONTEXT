# ADR-0010 — Persistent project truth is revisioned/append-oriented

**Record type:** SOURCE_DERIVED_ADR  
**Authority:** DOC-C, DOC-D  
**Scope:** CURRENT_REQUIRED

## CONTEXT
Overwriting project artifacts/history destroys provenance and makes rollback/audit ambiguous.

## OPTIONS
1. Overwrite rows/files in place
2. Store only latest state
3. Create revisions/commits with optimistic concurrency and immutable lineage

## DECISION
Content mutation creates new Revision; commits bind existing revisions; historical lineage is preserved.

## WHY
- Supports provenance/rollback.
- Prevents silent rewrite.
- Enables audit and OCC.

## CONSEQUENCES
- Storage/migrations must preserve lineage.
- Hard delete is exceptional/authorized/audited.
- Restore requires valid parent/blob lineage.

## SUPERSEDES
None explicitly recorded.

## ROLLBACK / CHANGE BOUNDARY
Would require storage-model migration and explicit policy change.
