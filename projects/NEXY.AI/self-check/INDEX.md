# NEXY.AI AI Self-Check Protocol

Before declaring completion, an AI must verify:

- [ ] correct authority/source
- [ ] exact current target HEAD
- [ ] evidence-class separation
- [ ] no unsupported material inference
- [ ] supersession/conflict resolution
- [ ] authorized scope/mutation
- [ ] change impact calculated
- [ ] S4/S5 invariants preserved
- [ ] contract/FSM/state/security semantics checked
- [ ] failure/regression history searched
- [ ] required tests executed/inspected
- [ ] evidence class matches claim
- [ ] evidence is fresh
- [ ] impacted regression checked
- [ ] final diff/scope inspected
- [ ] unknowns/blockers exposed
- [ ] task-specific Definition of Done satisfied
- [ ] checkpoint/handoff updated when needed

## Fail-closed rule
If a material box is unchecked, do **not** collapse the result to PASS.

Use the precise state:
`FAIL / PARTIAL / BLOCKED / NOT_VERIFIED / UNKNOWN / CONFLICT`.
