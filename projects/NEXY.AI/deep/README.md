## Purpose

This directory is a source-derived capture of the full design document `แอป [NEXY-IGNIS] ที่กำลังพัฒนา.docx`. ## Method

Read source incrementally → classify each statement → normalize terminology → record dependencies/authority/failure behavior → write to AI-CONTEXT → continue with the next source range.

## Evidence semantics

- **SOURCE-DESIGN**: explicitly described in the design source.
- **CANON/LOCKED-IN-SOURCE**: source text explicitly marks it locked/canonical. This is not implementation proof.
- **BUILD-SPEC**: appears in DOC-C/build-oriented material.
- **VISION/FUTURE**: architecture or future direction, not current build authorization.
- **UNRESOLVED**: source itself leaves a conflict, missing constant or undefined procedure.
- **NOT VERIFIED RUNTIME**: no runtime/physical/deployment proof inferred from prose.
