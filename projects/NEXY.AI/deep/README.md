# NEXY.AI Deep Source Capture

## Purpose
This directory is a streaming, source-derived capture of the full design document `แอป [NEXY-IGNIS] ที่กำลังพัฒนา.docx`. It exists because the source is much larger than a single model context window and the earlier 215-system inventory compresses many laws, protocols, state machines, invariants and execution planes into single labels.

## Method
Read source incrementally → classify each statement → normalize terminology → record dependencies/authority/failure behavior → write to AI-CONTEXT immediately → continue with the next source range.

## Evidence semantics
- **SOURCE-DESIGN**: explicitly described in the design source.
- **CANON/LOCKED-IN-SOURCE**: source text explicitly marks it locked/canonical. This is not implementation proof.
- **BUILD-SPEC**: appears in DOC-C/build-oriented material.
- **VISION/FUTURE**: architecture or future direction, not current build authorization.
- **UNRESOLVED**: source itself leaves a conflict, missing constant or undefined procedure.
- **NOT VERIFIED RUNTIME**: no runtime/physical/deployment proof inferred from prose.
