# NEXY.AI Regression Ledger

## Purpose
Turn historical failures into mandatory regression intelligence.

## Files
- `regressions.jsonl` — 24 records.
- `validation-report.md`

## Query rule
Before patching:
`affected entity → Change Impact Map → known failure IDs → Regression Ledger → required regression tests/prevention`

Resolved failures remain valuable because their regression obligations survive the original fix.

Active/blocking findings remain blockers, not “known-good history.”
