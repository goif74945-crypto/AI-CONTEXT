# NEXY.AI Golden Example Corpus

## Purpose
Source-derived examples of **correct reasoning/behavior patterns** for AI builders and auditors.

These examples are not runtime evidence. They teach expected behavior and route the AI to authoritative context.

## Files
- `golden.jsonl`
- `validation-report.md`

## Current categories
- CURRENT_STATE
- RELEASE
- FSM
- UI_TRUTH
- QUEUE
- AUTHORITY
- LEARNING
- SCOPE
- PERSISTENCE
- INPUT

## Rule
A Golden example may illustrate a correct contract but never upgrades implementation/runtime status to PASS.
