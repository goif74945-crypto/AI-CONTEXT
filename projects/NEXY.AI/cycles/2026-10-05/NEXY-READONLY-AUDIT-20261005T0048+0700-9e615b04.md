### F-001 — TSA elapsed-time authority is required by the current-build queue, but no production injection path was observed

**Classification:** REPO_FACT + deterministic code-path inference  
**Severity:** P0 current-build availability blocker candidate  
**Runtime verification:** NOT VERIFIED

At exact revision `9e615b04...`:

- `packages/core/tick.ts`
  - initializes `TSA_BATCH_TIME_MS = null`;
  - exposes `injectTsaBatchTime(batchTimeMs)`;
  - makes `currentTsaBatchTimeMs()` throw `TSA_BATCH_TIME_REQUIRED` when no TSA batch exists;
  - explicitly states elapsed-time consumers must use TSA time, not logical `currentTick()`.
- `packages/api/bootstrap.ts`
  - hydrates state and calls `setEpochBase(maxPersisted)`;
  - does not inject a TSA batch.
- `apps/web/instrumentation.ts`
  - invokes only `bootstrap()` before request handling.
- `packages/queue/dispatch.ts`
  - calls `currentTsaBatchTimeMs()` through `requireQueueAuthorityTimeMs()`;
  - converts absence into `TSA_TIME_AUTHORITY_UNAVAILABLE`;
  - therefore cannot enqueue a normal directive without TSA authority.
- `packages/queue/workers.ts`
  - calls `currentTsaBatchTimeMs()` at consume-boundary stale validation;
  - therefore fails closed if the worker process has no injected TSA batch.
- repository search for `injectTsaBatchTime` returned only Core/tests in the inspected index; no production ingress caller was observed.
- production runbook starts the worker directly with `node --import tsx packages/queue/workers.ts`.

**Important distinction:** removing `Date.now()` from authoritative queue TTL logic is correct. The blocker is not the fail-closed rule. The blocker is requiring a trusted authority value without an observed production trust-boundary path that supplies it.

**Required recovery design:**

1. define an explicit production TSA ingress with provenance/verification;
2. inject trusted batch time before queue producer and worker elapsed-time decisions;
3. keep missing authority fail-closed;
4. never restore host-clock fallback;
5. add production-like positive and negative integration proof;
6. bind DOC-E E7 queue-readiness evidence to that exact ingress.
