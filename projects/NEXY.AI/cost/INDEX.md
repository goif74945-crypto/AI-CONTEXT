# NEXY.AI Resource / Cost Model

## Purpose
Give AI a cost-aware planning layer without fabricating provider prices or infrastructure bills.

## Files
- `resource-cost-model.json`
- `validation-report.md`

## Core rule
**Cost is subordinate to authority, integrity and required evidence.**

The registry models cost drivers and optimization levers. Monetary rates remain UNKNOWN unless a current authorized source provides them.

## Main resource classes
- RC-MODEL-INFERENCE: External model inference
- RC-PIPELINE-COMPUTE: DOC-C pipeline compute
- RC-PERSISTENCE: Metadata / blob / history storage
- RC-LO2-KNOWLEDGE: Lo2 verified knowledge corpus
- RC-GAME: AAAA Game Fabric resources
- RC-ROBOTICS: Robotics compute/hardware
- RC-EVIDENCE: Verification / evidence generation
