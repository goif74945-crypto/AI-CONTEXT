# NEXY.AI Definition-of-Done Registry

## Purpose
Different work types have different completion criteria.

`BUILD PASSED` is not a universal definition of done.

## Files
- `definitions.jsonl` — 8 task-specific definitions.
- `definition.schema.json`
- `validation-report.md`

## Rule
A task may be:
- implemented but NOT VERIFIED;
- tested but not deployment-ready;
- structurally complete but lacking runtime proof;
- blocked by authority/external evidence.

Use the task-specific definition, not a generic green check.
