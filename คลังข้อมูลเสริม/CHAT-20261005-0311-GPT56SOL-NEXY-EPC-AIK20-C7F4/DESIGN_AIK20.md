# AIK20 Design Summary

AIK20 exists because “evidence exists” does not imply “the decision is identified.” A proposal may rely on hidden premises or several rival explanations can fit the same observations while implying different EPC outcomes.

The twenty mechanisms are:
1. ARC — Assumption Registry Completeness
2. ACG — Assumption Closure Graph
3. CAG — Contradictory Assumption Gate
4. ADG — Assumption Discharge Gate
5. RAB — Residual Assumption Budget (checked Q64.64)
6. HPL — Hidden Premise Leakage
7. UAC — UNKNOWN-to-Assumption Coercion Guard
8. SBG — Assumption Scope Binding Gate
9. PVB — Assumption Provenance Binding
10. DCB — Defeater Coverage Binder
11. UDG — Undefeated Critical Defeater Gate
12. HCF — Hypothesis Compatibility Filter
13. UDD — Outcome Underdetermination Detector
14. OEP — Outcome Equivalence Partition
15. EEX — Evidence Exclusivity Index
16. PSM — Pairwise Separability Matrix
17. IWG — Identifiability Witness Gate
18. NIF — Non-identifiability DEFER Advice
19. ASM — Assumption State Monotonicity
20. AIC — Assumption & Identifiability Court Capsule

Important semantic rule: two explanations that differ internally but imply the same court action are not treated as harmful underdetermination. The hard blocker is multiple decision-distinct outcomes surviving the same verified observations.

All outputs remain advisory. AIC always carries `LO4_ADVISORY_ONLY`; NIF can advise DEFER but never changes NEXY state.
