# Contradiction Ledger
Status: PROPOSAL
Contradictions must be preserved, classified and resolved by authority/scope/time/evidence rather than blended.

Record: contradiction_id, proposition_key, claims, source identities, authority ranks, scopes, type, resolution_state, resolution_rule, downstream affected claims, recheck triggers.

Types: NORMATIVE, IMPLEMENTATION, RUNTIME, TEMPORAL, SCOPE, TERMINOLOGY, COUNT, PROVENANCE, SECURITY, UNKNOWN.

Resolution:
- authority-resolvable: preserve both and record governing rule;
- scope-resolvable: split scope;
- temporal-resolvable: assign eras;
- evidence-resolvable: rerun correct verifier;
- unresolvable: CONFLICT/FREEZE.

Never use newest prose, AI majority vote, detail level, or silent rewrite as authority.

Contradiction debt metrics: open_critical, open_noncritical, resolved_with_rule, scope_split, stale_unrechecked, downstream_blocked.
Zero contradictions is not automatically healthy because deletion can hide evidence.
