# 20 Lo4 concepts

1. **Model Route Stabilizer** — Selects the best model/provider deterministically from quality, latency, cost, safety, and stability signals.
2. **Context Salience Field** — Ranks context chunks by relevance, authority, freshness, user priority, and contamination risk.
3. **Compute Budget Allocator** — Allocates finite compute/tokens across work items with exact Q64.64 proportional accounting.
4. **Backpressure Governor** — Converts queue saturation, error pressure, and latency pressure into deterministic admission and degradation levels.
5. **Personalization Drift Limiter** — Bounds preference updates so personalization evolves without abrupt profile drift.
6. **Safety Margin Envelope** — Combines hazard likelihood, impact, containment, and reversibility into a hard safety admission envelope.
7. **Mutation Option Valuator** — Values proposed mutations using utility, reversibility, blast radius, rollback cost, and evidence strength.
8. **Recovery Path Planner** — Ranks recovery plans by restoration probability, time, side effects, evidence, and reversibility.
9. **Lo4 Promotion Gate** — Gates Lo4 proposals before Canon promotion using evidence, determinism, security, regression, and integration readiness.
10. **Consensus Weight Resolver** — Aggregates multi-agent verdicts with trust-weighted deterministic margins and abstention handling.
11. **Freshness Discount Engine** — Applies deterministic time discount to evidence and cached decisions without floating-point drift.
12. **Privacy Budget Governor** — Accounts data-exposure cost against a fixed privacy budget and denies over-budget operations.
13. **Fair Queue Credit Scheduler** — Schedules agents/users with deterministic credit accrual and starvation resistance.
14. **Latency Precision Governor** — Chooses reasoning precision from task importance, urgency, latency headroom, and uncertainty.
15. **Memory Retention Ranker** — Ranks durable-memory candidates by future utility, authority, uniqueness, freshness, and privacy cost.
16. **Tool Call Governor** — Approves or ranks tool calls using expected utility, confidence, latency, monetary cost, and mutation risk.
17. **Incident Severity Aggregator** — Produces deterministic incident severity from impact, reach, exploitability, irreversibility, and active spread.
18. **Predictive Prefetch Ranker** — Ranks likely future resources for prefetch using probability, utility, size cost, freshness, and waste risk.
19. **Swarm Duty Allocator** — Allocates task duty across agents using capacity, fitness, trust, load, and failure reserve.
20. **Intent Stability Filter** — Detects oscillating or unstable intent and blends current/prior intent signals with deterministic hysteresis.
