# Counterfactual Analysis Protocol
> AI-PROPOSED CONCEPT.
C0 assign CF-ID and exact baselines.
C1 state minimal delta.
C2 project affected requirements: PRESERVED/STRENGTHENED/WEAKENED/REINTERPRETED/CONFLICT/UNKNOWN.
C3 construct W0 baseline, W1 proposal, Wf failures, Wr recovery.
C4 challenge authority, determinism, provenance, freeze, least authority, idempotency, recovery, compatibility, observability, security, evidence freshness.
C5 test stale state, mixed versions, partial rollout, rollback-after-write, duplicate side effects, gate bypass, stale evidence.
C6 ADOPT-CANDIDATE means design gate met only, never production readiness.
