# Promotion & Evidence Gates
> AI-PROPOSED CONCEPT.
G0 IDEA: no authority.
G1 SPECIFIED: contracts/invariants/failure semantics.
G2 STATIC: schemas/interfaces/static checks.
G3 ISOLATED: unit/model proof.
G4 INTEGRATED: dependencies exercised.
G5 FLOW: end-to-end behavior.
G6 OPERATIONAL: fault/load/recovery runtime evidence.
G7 DEPLOYMENT: exact build/environment proof.
G8 PHYSICAL: HIL/physical proof when relevant.
Gate is claim-specific. Numeric order never permits evidence-class substitution. Material delta invalidates the affected evidence slice.
