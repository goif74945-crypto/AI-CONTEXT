# Adoption Boundary

Status: **AI-PROPOSED**

This lab can be useful without being merged into NEXY.AI.

## Low-risk use now
- regression corpus for AI workflow design;
- offline audit of structured agent traces;
- research into clarification debt and scope drift;
- deterministic acceptance gate prototypes.

## Not authorized by this work
- production integration;
- changes to NEXY core/JUDGE/LAW/DIALOG;
- automatic freezing of live user tasks;
- treating the score weights as canonical policy;
- using raw-model extraction as authoritative user intent.

## Preconditions before any production adoption
1. Map fields to canonical NEXY authority contracts.
2. Define exact scope grammar.
3. Tie evidence references to immutable identities.
4. Establish freshness/invalidation behavior.
5. Red-team omitted-directive extraction.
6. Validate false-positive cost on real workflows.
7. Obtain explicit project authorization for implementation.
