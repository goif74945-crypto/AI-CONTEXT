# Future Systems Proposed by AI

> **ALL ITEMS IN THIS FILE ARE AI-PROPOSED CONCEPTS. THEY ARE NOT CURRENT NEXY.AI REQUIREMENTS.**

## 1. NEXY Interruption Scheduler
Schedule required human interruptions at semantically safe boundaries so independent questions can be bundled without delaying critical safety/authority decisions.

## 2. Choice Topology Compiler
Convert large flat option sets into deterministic hierarchical choices while preserving every legally/semantically required option. The compiler would measure information loss and reject lossy compression.

## 3. Authority Envelope Cache
Cache only explicit, scoped, expiring user preauthorizations, never inferred preferences. Every cached authority record would include scope, expiry, provenance, revocation rule, and the exact actions it can cover.

## 4. Friction Shadow Mode
Observe proposed interaction plans without changing production behavior. Compare predicted vs observed human touches, wait exposure, abandonment, corrections, and overrides before enabling any optimization.

## 5. Counterfactual Flow Runner
Replay the same task contract against multiple interaction policies and generate a Pareto set across authority preservation, safety findings, completion latency, and human effort.

## 6. User-Selected Interaction Profiles
Allow explicit profiles such as `EXPERT_COMPACT`, `GUIDED`, or `ACCESSIBLE_LOW_SWITCH` while keeping governing safety/authority invariants immutable. Profiles would alter presentation budgets, not truth or law.

## 7. Confirmation-Fatigue Regression Corpus
Maintain adversarial examples where excessive confirmations caused users to mechanically approve dangerous actions. Evaluate whether new flows preserve meaningful confirmation while reducing routine noise.

## 8. Interaction SLOs
Define measurable service-level objectives such as maximum blocking touches for reversible tasks, maximum foreground wait exposure, and maximum unresolved-choice entropy, with domain-specific exceptions.
