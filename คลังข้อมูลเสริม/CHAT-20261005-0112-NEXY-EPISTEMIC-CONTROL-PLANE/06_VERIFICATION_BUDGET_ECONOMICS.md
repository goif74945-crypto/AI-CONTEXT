# Verification Budget Economics
Allocate verification effort by expected loss, not token volume.
Inputs: severity, reversibility, uncertainty, freshness, blast radius, authority ambiguity, novelty, external side effects, security sensitivity.
Suggested tiers V0 formatting through V4 irreversible/high-impact/security/safety critical.
Stop additional verification only after acceptance evidence is satisfied and no unresolved high-severity contradiction remains.
More agents and more tokens are not evidence-quality metrics.
