# Negative Knowledge Registry
Persist impossible, deprecated, invalidated, unsafe, unsupported, rejected or temporarily blocked knowledge.
Types: IMPOSSIBLE_UNDER_CONSTRAINTS, DEPRECATED, INVALIDATED_ASSUMPTION, KNOWN_BAD_PATTERN, UNSUPPORTED_CLAIM, REJECTED_DESIGN, TEMPORARILY_BLOCKED, DO_NOT_USE_AS_DENOMINATOR.
Each record: reason, authority/evidence, date, scope, revisit condition, superseding record.
SOURCE_FACT example: historical 215-entry registry is deprecated/unreliable; overview records 837 normalized requirement rows.
Framework: DESIGN PROPOSAL.
