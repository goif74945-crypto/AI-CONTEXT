# Anti-Consensus: Correlated Agent Failure
Ten agents are not ten independent witnesses when they share model lineage, prompt, retrieval source, parser, runtime, or environment.
Record independence dimensions: model/provider lineage, prompt lineage, retrieval lineage, tool/runtime lineage, parser lineage, environment, observation time.
High agreement plus low evidence diversity is a red-team trigger, not automatic confidence.
Prefer proposer, falsifier, source auditor, boundary checker, runtime verifier and judge roles; collect independent first-pass findings before peer exposure when feasible.
