# Novelty and Collision Audit

## Audit rule

Name difference is not novelty. The comparison criterion is semantic responsibility: inputs, authority, state transitions, failure behavior and evidence output. A similar acronym is irrelevant; overlapping authority/function is what matters.

## Existing AI-CONTEXT surfaces inspected before design

The current corpus already contains or concurrently develops Proposal Forge, proof/evidence capsules, counterfactual temporal verification, decision replay, proof compiler, metamorphic assurance, multiple Q64 utility/value/Anti-Goodhart labs, EPC causal/evidence governance, EPC Court Foundry, EPC evolutionary ecology/integration, and EPC adversarial integration testing.

Those systems made several tempting ideas unavailable to this work. FCVF therefore does **not** generate proposals, score idea quality, package generic proof capsules, implement generic replay, calculate promotion utility, map integration blast radius, or own NEXY promotion.

## Distinct responsibility

FCVF owns **formal constitutional protocol verification**: a finite transition model of the EPC rules, lifetime vote-right safety, protected-authority non-interference, bounded exhaustive reachability checks, deterministic counterexample minimization, and strict-vs-weakened constitutional regression differentials.

The pre-design commit search found no direct AI-CONTEXT commit surface for the phrases `model checker`, `temporal logic`, `noninterference`, `ballot protocol`, `proof carrying ballot`, `monotonic evidence`, or `formal verification`. This is evidence of a gap, not proof that no semantically adjacent code exists anywhere in the entire repository. Accordingly, novelty status is **evidence-backed distinct in the inspected corpus**, not a universal originality claim.

## Controlled overlap

Some primitives intentionally overlap because compatibility requires them: Q64.64, deterministic canonical ordering, evidence provenance, freeze/fail-closed behavior and no-authority promotion boundaries. Those are architectural constraints inherited from NEXY, not claimed inventions. FCVF's novelty is the composition of those constraints into a constitutional model-checking fabric for EPC.

## Known collision risk

Concurrent chats continue writing AI-CONTEXT. A future system may independently create a formal EPC verifier after this audit. Such later overlap should be resolved through semantic comparison and the EPC vote protocol, never by physical deletion or filename similarity.
