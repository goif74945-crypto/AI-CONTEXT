2. None may convert advisory metadata into evidence by itself.
3. `ESC:SATURATED` is not consensus and not verification.
4. `UIS:STABLE` proves only output invariance over its declared finite model; unknown facts remain unknown.
5. `EECP:PLAN` identifies a proof route; actual evidence execution is still required.
6. `MFWR:ONE_MINIMAL` proves only 1-minimality relative to the supplied deterministic failure oracle and evaluation boundary.
7. `ICK:PASS` means its local conservation rules held; authorization receipts themselves still require upstream validation.
8. Adapters must bind every artifact to exact revision/configuration identity before production use.
9. Any mismatch between these proposal contracts and authoritative NEXY law must FREEZE adoption, not reinterpret NEXY.
