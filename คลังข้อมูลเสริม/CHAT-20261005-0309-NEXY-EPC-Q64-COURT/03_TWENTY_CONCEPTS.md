# Twenty EPC Innovations

All 20 entries are **AI-PROPOSED CONCEPTS**. Their implementation mapping is enforced by `src/concepts.ts` and the test suite.

1. Case Capsule Compiler — complete typed vote/evidence envelope.
2. Two-Round Entitlement Ledger — one KEEP and one CUT for each CHAT_ID lifetime.
3. Non-Vote Disposition Lane — DEFER / INSUFFICIENT_EVIDENCE / WIP without consuming a round.
4. Append-Only Verdict Chain — hash-linked immutable decision history.
5. Evidence Revision Lineage — corrections append, never rewrite verdict history.
6. Snapshot Freshness Binder — exact Spec/NEXY/AI-CONTEXT identity per vote.
7. Canon Supremacy Firewall — votes/scores cannot outrank Canon/LAW/CORE/JUDGE.
8. WIP Immunity Gate — incomplete construction is not grounds for elimination.
9. Unknown-as-Cut-Proof Ban — uncertainty cannot be converted into adverse evidence.
10. Semantic Duplicate Burden Engine — duplicate requires exact target + multi-dimensional semantic proof.
11. Conflict Citation Resolver — Canon conflicts cite path/symbol/commit/evidence.
12. Q64.64 Court Scoring Kernel — deterministic fixed-point scoring only.
13. Score Non-Sovereignty Rule — score never defeats hard authority gates.
14. Counterargument Completeness Gate — every final vote includes a real opposing case.
15. Dependency Closure Gate — promotion preparation blocked by unresolved dependencies.
16. Cut-is-Classification Law — CUT means archive/reject/supersede, never physical deletion.
17. Promotion Barrier Packet — packages evidence for review without authorization.
18. JUDGE Boundary Adapter — exports advisory evidence back toward the authoritative JUDGE boundary.
19. Tamper-Evident Replay Verifier — detects payload/order alteration and, with sealed head+length, tail truncation.
20. Deterministic Court Replay — same request + snapshot + policy + ledger yields identical output.

These are implementation concepts inside EPC, not new NEXY Canon requirements.
