# Future NEXY Integration Proposal — NON-CANON

This document is an AI proposal, not a build requirement.

## Proposed boundary
NEXY should expose only an adapter-safe snapshot to the chamber:
- immutable proposal identifier;
- declared behavior contract;
- explicit evidence references;
- declared requested capabilities;
- trace corpus explicitly approved for experiment use;
- hard constraints copied from authoritative law by a trusted adapter.

The chamber should return only:
- novelty report;
- experimental invariant candidates + counterexamples;
- least-capability integration plan;
- experimental guard proposals;
- tournament review packet.

## Explicitly forbidden return path
The chamber must not directly:
- modify User Law;
- modify NEXY Canon;
- execute external tools;
- grant capabilities;
- promote experimental invariants;
- publish a winner as production behavior.

## Suggested promotion path
`Lo4 proposal -> isolated test -> adversarial test -> independent verifier -> human/Canon authority decision -> formal promotion record`

Until that path is formally adopted by NEXY authority, all outputs remain advisory.
