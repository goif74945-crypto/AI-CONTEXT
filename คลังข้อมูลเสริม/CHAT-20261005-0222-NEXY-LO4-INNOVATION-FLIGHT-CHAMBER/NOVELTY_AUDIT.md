# Novelty Audit

## Baseline observed
The supplemental root contained 201 entries when inspected in this session. Recent projects already cover lexical collision guarding, proof capsules, semantic patches, tool-contract drift, model substitution, human authority, proof efficiency, shadow execution/integration, causal merge, concurrency, and multiple five-concept assurance packs.

## Search evidence
Repository code-search queries for these mechanism phrases returned no matches at inspection time:
- `behavioral novelty fingerprint contract fingerprint`
- `invariant discovery quarantine mined invariants`
- `integration surface minimizer least authority adapter`
- `architecture tournament evolutionary design candidate winner`

This is evidence of no matching indexed phrases, not proof that no conceptual overlap exists anywhere.

## Differentiation
- BNF is structured behavior-contract similarity, intentionally complementary to the existing lexical Collision Guard.
- IDQ is observation-derived invariant mining with an explicit no-auto-promotion barrier.
- ISM computes the least dependency closure and rejects protected capabilities before integration.
- CGD converts labeled counterexamples into the smallest safe candidate predicate conjunction, with human review required.
- ETE provides deterministic evidence-gated competition among multiple Lo4 proposals and explicitly permits no winner.

## Novelty status
`PARTIAL / NOT GLOBALLY PROVEN`.
The mechanisms are distinct from the sampled and searched work, but semantic uniqueness across all 201 projects cannot be mathematically guaranteed by repository-name and indexed phrase inspection alone.
