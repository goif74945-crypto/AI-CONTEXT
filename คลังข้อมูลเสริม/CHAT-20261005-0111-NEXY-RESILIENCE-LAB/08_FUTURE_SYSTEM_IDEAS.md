# Future-System Ideas
These are proposals, not claims about current NEXY.AI implementation.

1. Evidence DAG: requirements → implementation claims → tests → observations; changed nodes invalidate dependent proof.
2. Authority Compiler: derive machine-checkable invariants, protected paths, evidence classes, stop conditions from canonical human specs.
3. Verification Debt Meter: weight NOT_VERIFIED claims by blast radius, staleness, churn, and downstream consumers.
4. Context Entropy Budget: score duplicate claims, contradictions, stale records, orphan evidence, unsupported summaries.
5. Shadow Executor: simulate high-impact tool sequences against read-only snapshots and compare intended writes with authorized scope.
6. Failure Memory Router: retrieve prior failures by precondition signature.
7. Epistemic Circuit Breaker: ambiguity degrades autonomy WRITE → PLAN → READ_ONLY → FREEZE.
