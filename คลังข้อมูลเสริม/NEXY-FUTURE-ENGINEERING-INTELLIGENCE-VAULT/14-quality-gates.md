# Quality Gates
SPEC: objective, scope, immutable constraints, testable acceptance, labeled unknowns.
ARCH: ownership, trust boundaries, state transitions, failure behavior, compatibility.
READY: versioned contracts, secrets/config, observability, migration/rollback, test plan.
VERIFY: positive, negative, failure, security tests; evidence; no critical contradiction.
RELEASE: exact artifact, environment, bounded rollout, rollback/mitigation, telemetry.
COMPLETE: deliverables exist, criteria satisfied, outputs re-read, limitations stated, no fabricated success.
Any failed critical gate means status cannot be COMPLETE.
