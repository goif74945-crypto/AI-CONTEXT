## Scope lock

## Evidence classes
- FACT: directly verified from authoritative evidence.
- INFERENCE: logically derived and must name premises.
- ASSUMPTION: provisional; never promoted silently.
- UNKNOWN: unavailable evidence.
- NOT VERIFIED: claim exists but verification is incomplete.

## Core doctrine
1. Correctness before completion claims.
2. Fail closed for authority/security boundaries.
3. Fail explicitly for missing data.
4. Idempotency for retriable mutations.
5. Determinism where reproducibility matters.
6. Observable state transitions.
7. Contract-first interfaces.
8. Reversible migrations and bounded blast radius.
9. Evidence attached to every critical acceptance criterion.
10. No placeholder success.
