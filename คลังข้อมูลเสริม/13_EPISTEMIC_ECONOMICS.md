# Epistemic Economics
Status: PROPOSAL / AI-PROPOSED CONCEPT
Authority: ADVISORY ONLY

Verification costs compute, latency, human attention, storage, context and tool calls. Allocate discretionary verification effort according to consequence and uncertainty without weakening mandatory gates.

## Variables
impact
irreversibility
authority_weight
uncertainty
fanout
detectability
verification_cost

Planning priority rises with impact, irreversibility, authority, uncertainty and fanout, and rises as detectability falls. This is a heuristic, never authority.

## Tiers
V0 cosmetic/non-authority
V1 local reversible
V2 shared state
V3 canonical data/contract
V4 security/permission
V5 irreversible/external/release authority

Higher tiers deserve stronger evidence, tighter source identity and broader counterexample testing.

## Immutable restriction
If an authoritative contract mandates proof X, economics cannot waive X.

## Context budgeting
Spend context first on governing authority, evidence that can falsify the current plan, high-blast-radius dependencies, counterevidence, then implementation detail. Compress descriptive prose before authority, contradictions, thresholds or UNKNOWNs.

## Tool-call budgeting
Prefer discriminating experiments. One call that separates competing hypotheses is more valuable than ten broad searches.

## Human attention
Escalate for unresolved authority conflict, irreversible action beyond policy, ambiguity affecting intent, or structurally unavailable evidence. Do not escalate merely because work is long.

## Use
Potential future uses: choose audit depth, regression subsets, retrieval budget, experiment order and escalation strategy while hard gates remain absolute.
