# Pivot and Collision Audit

## Status
`REPO_FACT + DESIGN_DECISION`, scoped to this supplemental lab. It is not a global proof that no similar idea exists anywhere.

## Initial direction rejected
The first local draft explored preference/attention adaptation. Before publishing executable code, repository history inspection found prior work that already owned those responsibilities:

- `CHAT-20261005-0122-NEXY-PREFERENCE-SOVEREIGNTY-LAB` owns consent-bound preference state, scope, expiry, revocation, conflict and deterministic personalization resolution.
- `CHAT-20261005-0121-NEXY-HICF-LAB/06_SCOPED_PREFERENCE_MODEL.md` already proposes scoped preference semantics.
- `CHAT-20261005-0121-NEXY-EXPERIENCE-COMPILER` covers cognitive-load budgeting, progressive disclosure and interruption/notification economics.
- HICF interaction-friction budgeting and the Interaction Economics Lab already address clarification/user-friction economics.

Therefore EPVL, ACG and PDRG were rejected as insufficiently novel. Their local prototype files were deleted before final publication.

## Final novelty boundary
ICF does **not** replace NCAF runtime route choice. Its object is a set of competing **Lo4 innovation proposals**, not provider/runtime routes.

The final responsibility split is:

- IURS: proposal value under interval uncertainty and protected minima.
- COMET: evidence-backed overlap discount against already-funded ideas.
- SCTE: architecture/maintenance change-surface burden.
- DCPX: bounded exact proposal portfolio composition with diversity/dependencies/conflicts.
- RIVP: reversible experiment option-value planning after portfolio selection.

Commit-history searches at the time of design returned no direct commit-message hits for `innovation portfolio`, `portfolio optimizer`, `overlap discount`, `diminishing return`, `option value`, `budget allocator`, `branch and bound`, `complexity tax`, `maintenance burden`, or `complexity budget`. This is collision-screen evidence, not a formal proof of universal novelty.

## Collision rule
If future repository evidence shows a materially equivalent owner, ICF must be merged, narrowed, superseded or rejected rather than declaring duplicate work novel by wording alone.
