# Lo4 Candidate Set 001 — 20 AI-Proposed Systems

All entries are proposals, not Canon. Each must pass implementation, deterministic, security, compatibility, and evidence gates before promotion consideration.

1. **Proof-Carrying Proposal Capsule (PCPC)** — proposal artifact bundles design, dependency graph, hashes, tests and machine-verifiable promotion predicates.
2. **Deterministic Counterfactual Replay Lab (DCRL)** — replays candidate behavior against frozen event traces and compares state hashes without touching authoritative state.
3. **Semantic Overlap Proof Engine (SOPE)** — proves behavioral duplication using normalized contracts, effects and invariants instead of filename similarity.
4. **Canon Impact Lattice (CIL)** — maps every proposal edge to Canon/LAW/JUDGE constraints and freezes unresolved authority collisions.
5. **Evidence Entropy Governor (EEG)** — detects when many claims depend on few independent proofs, preventing evidence-count inflation.
6. **Adversarial Promotion Gauntlet (APG)** — deterministic suite that mutates inputs, ordering and boundary values while preserving reproducible seeds encoded as fixtures, not RNG.
7. **Q64.64 Utility Frontier Engine (QUFE)** — exact fixed-point multi-objective comparison without floating-point authority.
8. **Invariant Witness Compiler (IWC)** — converts proposal invariants into executable witnesses and negative tests.
9. **State-Divergence Microscope (SDM)** — identifies first deterministic tick/path where candidate and reference traces diverge.
10. **Dependency Blast-Radius Graph (DBRG)** — computes affected modules/contracts/tests before integration is attempted.
11. **Capability Non-Escalation Proof (CNEP)** — verifies a proposal cannot acquire authority absent from its declared capability envelope.
12. **Promotion Reversibility Envelope (PRE)** — requires rollback/replay compatibility evidence before a candidate can become promotion-ready.
13. **Cross-Layer Contract Synthesizer (CLCS)** — derives typed adapter contracts between Lo4 experiments and existing NEXY boundaries while forbidding direct Core mutation.
14. **Evidence Freshness Seal (EFS)** — invalidates stale conclusions when spec hash, NEXY commit, or dependency evidence changes.
15. **Deterministic Resource Budget Ledger (DRBL)** — Q64.64/integer accounting for CPU/memory/event budgets with explicit overflow behavior.
16. **Contradiction Minimal-Core Extractor (CMCE)** — reduces conflicting requirements/evidence to the smallest reproducible contradiction set and FREEZEs only affected scope.
17. **Proposal Lineage DAG (PLD)** — immutable ancestry for merged/superseded proposals, preventing recycled rejected ideas from masquerading as novel.
18. **User-Value Evidence Bridge (UVEB)** — keeps UX/value hypotheses separate from verified runtime evidence and requires measurable acceptance fixtures.
19. **Shadow Integration Harness (SIH)** — connects candidates through non-authoritative adapters and compares outputs without permitting writes to Core state.
20. **EPC Two-Round Ledger (ETRL)** — append-only KEEP/CUT entitlement ledger keyed by CHAT_ID, with DEFER/WIP/INSUFFICIENT_EVIDENCE outside vote consumption.
