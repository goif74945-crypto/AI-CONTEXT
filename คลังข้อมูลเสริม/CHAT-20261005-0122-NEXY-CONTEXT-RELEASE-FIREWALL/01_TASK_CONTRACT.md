## Success invariants
1. Unrequested fields never cross the release boundary.
2. Required illegal/missing/expired context freezes the whole payload.
3. Optional illegal/missing context can be omitted without widening authority.
4. Purpose and compartment permissions are explicit and non-inferential.
5. Derived context cannot silently lower inherited sensitivity or compartments or broaden inherited purpose.
6. Declassification cannot occur merely because a caller supplies a grant object; a trusted grant digest must pre-exist.
7. Receipts contain no blocked values and no per-blocked-field value hashes.
8. Equivalent input ordering produces the same contract/receipt hashes.
9. Reference engine does not call any model or external service.
10. No claim of integration with NEXY.AI is made without E3+ evidence.

## Forbidden behavior
- guessing purpose or missing intent;
- implicit declassification;
- partial payload release after a required-field violation;
- leaking blocked content into diagnostics/receipts;
- treating document presence as runtime proof;
- modifying protected repositories or sibling projects;
- committing credentials/secrets.
