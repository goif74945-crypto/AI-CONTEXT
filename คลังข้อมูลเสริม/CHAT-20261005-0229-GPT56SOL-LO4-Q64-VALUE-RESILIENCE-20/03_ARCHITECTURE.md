# Architecture

## Boundary
This project is a standalone Lo4 candidate pack. NEXY can later call it through an adapter, but this package never assumes authority over NEXY::CORE, NEXY::LAW or NEXY::JUDGE.

## Layers
1. `q64.py` — signed checked Q64.64 arithmetic; overflow/domain/zero-division guards.
2. `contracts.py` — fail-closed input contracts, result type and release bands.
3. `engines.py` — twenty deterministic concept evaluators.
4. `canonical.py` — canonical JSON byte representation and SHA-256 replay identity.
5. `registry.py` — stable introspection surface.
6. `tests/` — arithmetic, contract, adversarial, determinism and composition verification.
7. `evidence/` — captured commands/results generated by `run_verification.py`.

## NEXY integration proposal
`NEXY task state -> adapter -> normalized unit Q64 inputs -> Lo4 evaluator -> candidate Evaluation -> NEXY verification/policy -> NEXY::JUDGE`

The returned `Decision` is only a proposal. NEXY retains final authority and may reject or freeze regardless of Lo4 output.
