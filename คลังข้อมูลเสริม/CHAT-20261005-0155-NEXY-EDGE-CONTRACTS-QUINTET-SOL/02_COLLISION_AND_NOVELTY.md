# Collision and Novelty Record

## Observed repository frontier
The supplemental tree contained 1,158 files and 290 directories at inspection time. Existing projects already cover, among other domains: proof sensitivity, semantic patch governance, provenance taint, deterministic interchange, concurrency/interleaving verification, side-effect transactions, counterfactual safety, context fidelity, privacy egress, human authority, delegation leases and shadow integration.

- interleaving/concurrency verifier;
- semantic patch scope governor.

## Selected novelty boundaries
### NAES
Not a generic authority lease. It binds **one approval to one exact execution plan/version** with explicit stale-approval and TOCTOU rejection.

### NECP
Not an evidence ledger. It solves **what exact tests/evidence should be acquired next**, under deterministic cost/risk optimization and prerequisite constraints.

### NSAC
Not contract-drift detection. It attempts **provably safe automatic compatibility synthesis**, and freezes when a transformation is ambiguous or lossy.

### NCCQ
A prior epistemic note warns that correlated agents are not independent witnesses. NCCQ's new contribution is an **executable exact set-packing/quorum certificate** over declared failure domains, turning that principle into a deterministic gate.

### NPMA
Not ordinary policy validation. It checks a global safety property: a policy surface must be **order-preserving with risk**, so a riskier state cannot become less restricted merely because thresholds interact badly.

## Limitation
Path and content inspection cannot prove philosophical uniqueness across all possible unpublished ideas. Novelty here means non-duplication against the observed AI-CONTEXT supplemental corpus and materially distinct operational responsibility.
