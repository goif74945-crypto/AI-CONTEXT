This lab contains five standalone deterministic reference systems proposed for future compatibility with NEXY.AI. It deliberately does **not** modify any repository whose name contains `NEXY.AI`.

The five concepts are:

1. **NAES — NEXY Approval Escrow Seal**: binds human authorization to an exact plan hash, directive epoch, expiry, mutation budget and scope so stale or widened approvals fail closed.
2. **NECP — NEXY Evidence Closure Planner**: computes the exact lowest-cost evidence acquisition plan needed to move target claims from current evidence state to their required evidence class.
3. **NSAC — NEXY Safe Adapter Compiler**: synthesizes only structurally provable, non-ambiguous compatibility adapters between typed field contracts and freezes on unsafe semantic drift.
4. **NCCQ — NEXY Correlation-Cut Quorum**: prevents false multi-agent consensus by requiring an exact quorum whose witnesses do not share declared critical failure domains.
5. **NPMA — NEXY Policy Monotonicity Auditor**: proves that increasing declared risk cannot paradoxically produce a less restrictive decision across a finite policy surface.

## Why these five

The current supplemental repository already contains systems for proof capsules, semantic patch control, context fidelity, provenance taint, concurrency/interleaving, counterfactual safety, privacy firewalls, authority leases and other heavy topics. This lab targets five narrower gaps at the boundaries between those systems: **approval-to-execution TOCTOU**, **evidence acquisition optimization**, **drift detection-to-safe repair**, **correlated verification failures**, and **policy threshold paradoxes**.
