## Collision decisions

### EDRE
Not a generic release firewall or proof capsule. It models **dependency-directed revocation**: a changed artifact invalidates only evidence descendants and claims that rely on them, then emits deterministic revalidation order.

### SIQG
Not SWARM/JUDGE replacement. It verifies **independence of quorum members before counting them**, using provider/model/operator/context/evidence/reasoning dimensions. Existing NEXY can have many agents; SIQG asks whether those agents represent independent failure domains.

### ABRC
Not an execution policy parser. It compiles an explicit operation/resource dependency graph into a **transitive blast radius** and blocks protected/irreversible/unrecoverable impact before mutation.

### SPEF
Not a workflow executor or human-agency system. It computes a deterministic **maximal currently safe frontier** within an already-authorized internal DAG, preserving NEXY's final release law.

### RRPE
Not NEXY's existing freeze recovery FSM. It is a **pre-mutation reachability proof**: before risk is taken, demonstrate that an authorized route can reach a certified checkpoint while restoring required invariants.

## FACT / ASSUMPTION / UNKNOWN

**FACT**: the listed sibling projects were observed in AI-CONTEXT commit/file paths.  
**FACT**: the protected NEXY repository already has SWARM/JUDGE, evidence contracts, freeze recovery, TSA time and state guards.  
**ASSUMPTION**: no unobserved/private supplemental chat created an identical algorithm under a different unpublished folder after this scan.  
**UNKNOWN**: whether all five concepts would be accepted into future authoritative NEXY specifications. Adoption requires explicit future authority.

## Novelty claim boundary
This work claims **distinct scope relative to the observed sibling corpus**, not mathematical proof that no similar idea exists anywhere in software engineering or in an unobserved chat.
