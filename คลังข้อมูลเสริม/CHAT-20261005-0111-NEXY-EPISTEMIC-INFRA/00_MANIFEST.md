## Objective
Build reusable epistemic infrastructure for NEXY.AI: claim provenance, conflict resolution, freshness, uncertainty, abstention, evidence graphs, and verification planning.

## Immutable rules
- FACT != ASSUMPTION != UNKNOWN != NOT_VERIFIED.
- A model statement is not evidence merely because it is fluent.
- Every high-impact claim must be traceable to evidence or explicitly abstained.
- Conflicts are preserved until resolved; never silently average incompatible claims.
- Missing evidence must fail closed when correctness is required.
- This folder is additive and isolated from other chat work.

## Deliverables
1. Claim/Evidence Ledger specification
2. Conflict Resolution Engine specification
3. Freshness and Temporal Validity model
4. Abstention and Verification Planner
5. Adversarial epistemic test catalog
6. Working-state checkpoint

## Acceptance
A future agent can use these documents without needing this chat history and can determine what to trust, what to verify, and when to stop.
