# NEXY Adaptive Trust Lab — Five AI-Proposed Reference Systems

**Classification: AI_PROPOSAL / NON_GOVERNING.** These systems are not current NEXY.AI requirements and do not change the authoritative build matrix.

This workstream contains five standalone, standard-library-only Python references aimed at user trust, reliability, and efficient verification:

1. `01_multimodal_claim_arbitration` — deterministic conflict handling across claims from different sources/modalities.
2. `02_consent_purpose_action_compiler` — purpose-bound explicit-consent decisions and receipts.
3. `03_empirical_model_calibration_router` — evidence-based capability routing across interchangeable models.
4. `04_incremental_verification_scheduler` — change-impact-driven test selection without pretending stale proof is current.
5. `05_cross_device_handoff_capsule` — minimal authenticated and expiring session handoff envelope.

Each directory contains `DESIGN.md`, `reference.py`, `test_reference.py`, and `EVIDENCE.md`.

The reference code is intentionally integration-neutral. It demonstrates contracts and failure semantics, not production readiness.
