# Concept 2 — Progress Truth Ledger
AI-PROPOSED / NON-GOVERNING

**Problem:** “90% done” is often an unsupported social estimate rather than an evidence state.

**Contract:** every obligation has a stable ID and one explicit status. The ledger exposes a factual pass-count ratio, not a schedule forecast.

**Core invariant:** only an all-PASS finite obligation set permits COMPLETE. UNKNOWN prevents verification; duplicate IDs freeze accounting.

**Why it can help NEXY:** autonomous long tasks gain resumable truthful state without teaching the AI to hallucinate percentage completion.
