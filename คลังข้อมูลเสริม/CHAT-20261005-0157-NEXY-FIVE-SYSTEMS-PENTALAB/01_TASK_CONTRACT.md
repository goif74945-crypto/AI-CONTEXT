# Task Contract — NEXY Five Systems PentaLab

## Objective
Build five distinct deterministic future-concept systems that can interoperate with NEXY through future adapters, without changing any NEXY.AI repository.

## In scope
Design, reference code, tests, evidence, benchmarks, failure/fix history, and future integration contracts under this directory.

## Protected
Any repository with `NEXY.AI` in its name; unrelated AI-CONTEXT paths; canonical NEXY law/spec; secrets; deployment state.

## Acceptance
- five materially distinct concepts;
- Design + Code + Test + Evidence for each;
- fail-closed material ambiguity;
- deterministic replay/order tests;
- cross-system adversarial suite;
- local integration demonstration;
- measured scale behavior without production-SLA claims;
- exact published bytes read back and re-tested;
- no protected-repository mutation.

## Evidence classes
E0 presence/read-back, E1 compile/static syntax, E2 unit/adversarial tests, local E3 integration demo. E4-E7 are not claimed.
