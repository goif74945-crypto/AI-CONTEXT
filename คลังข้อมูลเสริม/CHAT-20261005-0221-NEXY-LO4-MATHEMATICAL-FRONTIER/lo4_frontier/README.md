# Five Lo4 Engines

Each subdirectory is an independent experimental work unit containing:
- `DESIGN.md`
- `engine.py`
- `test_engine.py`
- `EVIDENCE.md`

Shared independent/property validation is in `../lo4_frontier/test_properties.py` because those tests deliberately compare engines against cross-cutting or independent formulations.

No subdirectory has authority to mutate or promote NEXY Canon.
