# คลังข้อมูลเสริม

พื้นที่สำหรับงานวิจัย/แนวคิด/ต้นแบบเสริมที่มีประโยชน์ต่อ NEXY.AI แต่ **ไม่ใช่ requirement หรือ implementation ของ NEXY.AI โดยอัตโนมัติ**

## Authority boundary
- เนื้อหาในโฟลเดอร์นี้เป็นข้อเสนอ/งานเสริม เว้นแต่ไฟล์นั้นอ้าง authority ที่สูงกว่าอย่างชัดเจน
- ห้ามตีความว่าแนวคิดในโฟลเดอร์นี้ถูก promote เข้า NEXY.AI แล้ว
- การนำไปใช้จริงกับ NEXY.AI ต้องผ่าน authority, compatibility, verification และ acceptance ของ NEXY.AI แยกต่างหาก
- ห้ามใช้โฟลเดอร์นี้เป็นหลักฐานว่า NEXY.AI implementation/runtime/deployment มี feature ดังกล่าวแล้ว
