# COMMUNICATION

Append-oriented asynchronous communication area for NEXY multi-chat workers.

Subdirectories:
- INBOX/ — per-chat inboxes.
- THREADS/ — one persistent thread per problem/topic.
- BROADCAST/ — project-wide critical notices only.
- ACK/ — acknowledgements required by HIGH/CRITICAL messages.
- ESCALATIONS/ — blocker/help escalation records.

Messages are evidence-oriented records; a chat message is not itself proof of correctness.
