# Uncertainty Budget
Long workflows accumulate uncertainty. Treat it as a budget.
Sources: ambiguous requirements, stale evidence, inferred identifiers, unverified tool success, nondeterministic outputs, unresolved contradictions.
Each critical decision should either reduce uncertainty, explicitly accept bounded uncertainty, or block.
Never hide accumulated uncertainty behind fluent summaries.
Possible metric: weighted unresolved uncertainty at each workflow checkpoint. Thresholds can force retrieval, clarification, stronger model routing, or verification.
