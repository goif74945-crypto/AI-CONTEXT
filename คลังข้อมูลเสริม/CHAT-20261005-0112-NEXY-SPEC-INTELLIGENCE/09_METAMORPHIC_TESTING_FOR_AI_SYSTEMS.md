# Metamorphic Testing for AI Systems
When exact output oracles are brittle, test relations.

MR1 unrelated context cannot alter locked facts.
MR2 stronger authoritative evidence cannot reduce provenance.
MR3 narrower scope cannot add mutations.
MR4 fewer permissions cannot increase actions.
MR5 repeated idempotent requests yield equivalent durable state.
MR6 reordering independent inputs preserves result.
MR7 equivalent identifiers resolve canonically.
MR8 missing evidence downgrades FACT to UNKNOWN/NOT VERIFIED, never fabricated certainty.
MR9 paraphrase preserves MUST/MUST_NOT semantics.
MR10 retry after ambiguous failure cannot duplicate irreversible effects.

Compare properties, not prose equality.
