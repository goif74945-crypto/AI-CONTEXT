# Provider Extinction Drills
> AI-PROPOSED CONCEPT
Assume a critical external provider disappears instantly with no migration window.
## Drill classes
Model, vector/database, identity, payments, observability, search/retrieval, object storage, notification.
## Required artifact per dependency
Inventory; blast radius; export path; credential revocation; alternate interface; minimum survival mode; recovery verification; permanent-exit plan.
## Principle
An alternative vendor existing does not prove portability. Portability requires evidence that data, semantics, auth, procedures, and acceptance tests can move.
If unsafe behavior after dependency loss cannot be identified, the dependency is not operationally understood.
